# MetaThought v0.0.16

One shared engine for five fresh team-distribution trials. distribution-suite.json identifies the exact Queen checkpoint, reviewed handoff, variants and fresh run folders. All use Spark Contributor and the accepted unlabeled score footer.

workers.newborn_mode selects invitation, fit_pair, rotation, or hive_choice. It changes only initial placement/context; committed drones keep ordinary context and free overlapping membership. No new tables, counters, team-size quotas or routing calls.

Variant1 removes recruitment wording from Expand. Variant2 uses equal invited/alternative inquiry cards. Variant3 distinguishes new inquiry, recruitment and connections. Variant4 rotates fresh arrivals. Variant5 asks where another thinker would be most useful using equally brief cards across the hive before local history.

Run-WorkerExperiment.ps1 -Stage Prepare -ConfigPath variant-N.json prepares a fresh experiment with explicit handoff overrides. Analyze-DistributionSuite.py reads the five runs without changing their state. The operator pauses them with native worker-pause after enough matched-prefix evidence, then drains and saves final analysis.
