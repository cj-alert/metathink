## Observations

- Task result: independently recalculate both model fits and the distinguishing predictions. Keep this read-only mathematical check separate from drone ratings.
- Intellectual influence: show source contribution/offer ID and text, later recipient C/E entry, what was visible in that call, substantive change and consequence. Distinguish one-way uptake, feedback changing an earlier contributor, and candidate-only synthesis. Delivery, acknowledgement and self-claims are insufficient. Feedback may traverse more than two drones. Attribution is observational, not experimental proof of causality.
- Method comparison: show actual instruction changed, retained methods/trials, each drone's score/evidence/uncertainty, and Queen rationale. Report immediate return and whether evolution actually occurred. Count response opportunities only as diagnostics; a longer trajectory alone is not thinking improvement.
- Rejections: separate HTTP/provider refusal/incomplete/transport, Decisions parsing/refusal, assessment parsing, invalid Queen review and contract rejection. Preserve exact messages. Distinguish call attempts, Decisions questions and validation events; one failure may create several events.
- Cost: per-call model/actor/purpose, input/cached/output/reasoning usage, latency/status and estimated USD; separate base drones/Queen, meta assessment drones/Meta-Queen and new child trials. Cache is part of input; reasoning is part of output. Missing data means unknown cost or explicit uncertainty, not a free call. Debug logs stay developer-only.
