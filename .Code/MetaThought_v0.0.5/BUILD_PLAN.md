# MetaThought v0.0.5 correction process

Authorized scope: correct the meta-queen completion/context gap and show exact current prompts and scoring. Preserve v0.0.4 and all live outputs.

## Procedure and acceptance
1. Copy the flat v0.0.4 source into a new v0.0.5 folder; change the executable/config version. No new dependencies.
2. Supply attributed operational trial evidence at every controller decision, including action and return. Keep diagnostic runs and debug logs excluded.
3. Reuse the existing assess phase to assess the imported reference under the campaign criteria before the first action. Persist that assessment so action/return and explicit resume use it without replaying the reference hive.
4. Clarify the method-improvement objective and action/assessment/return prompts. The base problem is an experimental task; solving it alone does not complete the method inquiry. RETURN remains available with a methodological conclusion or explanation that no informative next experiment is warranted. No forced trial count, generation count, score gate or quota.
5. Preserve all scoring levels/weights and base-hive conditions. Test initial evidence/assessment visibility, immediate honest return, initial assessment failure/resume, later assessment resume, and the existing mutation/crossover/retest path using substituted model replies.
6. Run the local suite once after edits, build, verify the reported version, and review the correction. No live provider call is part of this correction.
7. Generate a verbatim prompt/rubric reference from saved config, document the decision and local proof, and report implementation separately from untested live behavior.
